## Project Overview

The Weather App is a web application developed using React.js that allows users to check current weather information for different cities. It fetches real-time weather data from a weather API and displays the results through a simple and user-friendly interface.

The application helps users access important weather details, including temperature, humidity, wind speed, and other weather conditions.

##  Project Objectives

- Display current weather information for a selected city.
- Fetch real-time weather data using an API.
- Provide a simple and interactive user interface.
- Display weather information in an organized format.
- Allow users to check weather conditions in multiple cities.

##  Features

-  Search for weather information by city name.
-  Display the current temperature.
-  Display humidity and feels-like temperature.
- Display wind speed.
-  Show current weather conditions.
- Check weather information for different cities.
-  Provide a responsive user interface.

## ⚙️ Installation and Setup

### Prerequisites

- Node.js and npm
- Visual Studio Code
- Git
- An OpenWeather API key

### Step 1: Clone the Repository

```bash
git clone https://github.com/ganeshathmakuri/weatherapp.git
```

### Step 2: Navigate to the Project Folder

```bash
cd weatherapp
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Configure the Weather API

The application uses the OpenWeather API to retrieve weather information.

### Step 5: Run the Application

For Create React App:

```bash
npm start
```

Open the local development URL shown in your terminal.

##  API Integration

The application uses the OpenWeather Current Weather API to retrieve weather details for a selected city.

### Weather Information Displayed

| Information | Description |
|---|---|
| Temperature | Current temperature in Celsius |
| Feels Like | Perceived temperature |
| Humidity | Amount of moisture in the air |
| Weather Condition | Current weather description |
| Maximum Temperature | Maximum temperature reported by the API |
| Minimum Temperature | Minimum temperature reported by the API |
| Wind Speed | Current wind speed |
